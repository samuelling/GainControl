# GAIN CONTROL

A point-and-click comedy murder mystery set in a university neuroscience department. Built on Sierra structure, with LucasArts humor, Gabriel Knight investigation, and thin line art on black in the spirit of the OP-1, Pocket Operators, Game & Watch and Q*bert.

A grad student suspects the department's rising star faked his breakthrough paper. Then people start dying.

- **Play the whole game (Acts I–V):** https://samuelling.github.io/GainControl/ (source in [game/](game/index.html)). The title screen lets you start at any unlocked act. Serve the folder over HTTP (the game uses ES modules), e.g. `cd game && python3 -m http.server`, then open http://localhost:8000.
- **On a phone:** play sideways. FULLSCREEN (title screen, HUD, or the F key) hides the browser where the browser allows it. iPhone Safari never does, so there it explains how to use Share → Add to Home Screen. Launched from that icon, the game runs edge to edge with no address bar. M mutes.
- **Mac and iPhone/iPad apps:** the same game, offline, in a native shell (the same arrangement as Townies). The game's files are copied into the app when it builds and served to a web view from a tiny server inside the app (`ios/GainControl/LocalServer.swift`, on 127.0.0.1:47360), so music, progress and the console work exactly as on the web. Links out (ChairQuest, Advisor Quest) open in the browser.
  - **Mac:** `macos/build.sh` builds GainControl.app (Apple silicon and Intel, macOS 13+) and `GainControl.dmg`. The *Mac app* workflow builds it on every change to `game/` and puts the dmg on the [Gain Control for Mac](https://github.com/samuelling/GainControl/releases/tag/mac-latest) release; it is signed and notarized once `bash macos/setup-signing.sh` has saved your Developer ID to the repo's secrets (the same certificate Townies uses), otherwise right-click › Open the first time. The window keeps the stage's 16:9; FULLSCREEN (or F, or ⌃⌘F) takes it full screen.
  - **iPhone and iPad:** open `ios/GainControl.xcodeproj` in Xcode, pick your phone and Run (team Y4HDFDP479, bundle id `com.samuelling.gaincontrol`; landscape only). Taps do what clicks do: tap a thing for its chooser, tap the floor to walk, tap an inventory item again to put it down. Haptics on some effects. The *iOS build* workflow compile-checks it and keeps iPhone and iPad simulator screenshots. `-GainControlHash act3` as a launch argument opens a test hash.
  - **Icon:** `ios/tools/icon.html`, drawn in the game's line language; `node ios/tools/make_icon.mjs` renders both app icons.
- **The Perception Console:** https://samuelling.github.io/GainControl/game/console.html. This is the dark booth's computer, also playable from the booth in the game. It has bistable demos (Necker cube, Rubin vase, motion quartet, structure-from-motion sphere), classic experiments (Carrasco, Ling & Read 2004 *Attention alters appearance*; Campbell & Robson's contrast sensitivity function; Posner cueing; mental rotation; Bouma crowding; number sense), and the PS 327 labs ported from MATLAB: horizontal–vertical, Müller-Lyer (magnitude estimation, adjustment, constant stimuli), visual search, Adelson's corrugated plaid and the motion aftereffect. Each fits its own results and saves CSV.
- **The Script Room (behind the scenes):** https://samuelling.github.io/GainControl/game/script.html. Read and edit every line of dialogue, hotspot and item, and see each act's logic as a graph of who sets which flag and what it unlocks. Edits are saved in your browser and the game uses them right away. EXPORT saves them as `overrides.json`; commit that file to `game/` and the edits become canon.
